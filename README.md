# Cathy Cleans - Professional Cleaning Services Website

A modern, responsive website for Cathy Cleans cleaning services built with React, TypeScript, and Vite.

## Features

- 🏠 Professional landing page with animated background
- 📱 Fully responsive design
- 🎨 Modern UI with smooth animations
- 📧 Contact form with email integration
- 🚀 Fast performance with Vite
- 📍 Deployed with base path `/clean/`

## Tech Stack

- React 18
- TypeScript
- React Router DOM
- Vite
- CSS3 with animations

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:5173/clean/` in your browser.

### Build

```bash
npm run build
```

The build output will be in the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```
